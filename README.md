## Resumo do projeto
A ideia de uma aplicação web surgiu ainda no meio do curso, quando eu e vários outros estudantes relatamos dificuldades em encontrar outros artigos desenvolvidos no campus. Não havia até o momento uma plataforma que centralizasse o acesso das produções acadêmicas de outros estudantes da rede IFC. O presente projeto foi uma proposta de criação de um repositório unificado para a publicação de trabalhos acadêmicos da instituição IFC-CAS. O projeto será desenvolvido em Next.js com Typescript e Tailwind CSS. O backend será desenvolvido utilizando Express e Prisma ORM para manipulação do banco de dados (MySQL).
